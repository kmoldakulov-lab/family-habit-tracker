# PRD: Семейный трекер привычек

**Статус:** v1 реализован и опубликован
**Владелец:** Kanat
**Дата:** 2026-08-21
**Ссылка на живой продукт:** https://claude.ai/code/artifact/051d7224-4436-4ad7-b504-1825c12d31f1
**Сопроводительный документ (методика):** `Семейная система мотивации.docx`

## 1. Проблема

Дети в семье проводят слишком много времени в смартфоне в ущерб учёбе, домашним делам и прогулкам. Родителям нужен не разовый запрет, а повторяемая система: понятные правила, видимая мотивация и минимальный технический контроль как страховка. В семье трое детей трёх разных возрастов (3–6, 11–14, 15–17 лет), поэтому система должна работать для всех сразу, но с разной механикой под возраст.

Ручной контроль (напоминания, устные договорённости) не масштабируется на трёх детей и быстро теряется без единого места, где видно, кто что сделал за неделю и сколько накопил.

## 2. Цели

- Снизить долю спонтанного экранного времени за счёт видимой альтернативы: баллы/звёзды за учёбу, дела по дому и прогулки.
- Дать каждому ребёнку личную, понятную его возрасту систему учёта — без необходимости объяснять таблицу для 15-летнего трёхлетнему.
- Сделать прогресс общим для семьи: и родитель, и ребёнок видят одну и ту же картину на любом устройстве без ручной синхронизации.
- Снизить нагрузку на родителя: не отдельное приложение с логином, не бумажная таблица, которую теряют.

### Метрики успеха (для родителя, неформально)
- Система используется больше 3 недель подряд (не заброшена после первой недели).
- Хотя бы 4 из 7 дней в неделю отмечаются по каждому ребёнку.
- Субъективно: меньше конфликтов "отдай телефон" по вечерам.

Продукт не собирает и не отправляет никакой аналитики — метрики оцениваются вручную самой семьёй по факту использования.

## 3. Пользователи

| Роль | Кто | Как использует |
|---|---|---|
| Родитель | Kanat (и второй родитель) | Настраивает правила и награды, участвует в закрытии недели по воскресеньям, начисляет/утверждает баллы |
| Дошкольник, 3–6 лет | ребёнок | Отмечает вместе с родителем, сам не читает интерфейс |
| Подросток, 11–14 лет | ребёнок | Отмечает сам ежедневно, обсуждает награды с родителем |
| Старший подросток, 15–17 лет | ребёнок | Отмечает сам, ожидается больше автономии и меньше контроля со стороны родителя |

## 4. Объём

### Входит в v1 (реализовано)
- Три персональные карточки — по одной на возрастную группу, с разным набором категорий и формулировок под возраст.
- Недельная таблица чек-боксов (Пн–Вс) на категорию, с весом в баллах/звёздах на категорию.
- Живой пересчёт суммы баллов за неделю при каждой отметке.
- "Закрытие недели" — баллы уходят в накопительный баланс, чек-боксы обнуляются, событие попадает в историю.
- "Сброс недели" — отмена без начисления (для исправления ошибок), с защитой от случайного нажатия (двойное подтверждение).
- Магазин наград на каждой карточке: название и стоимость редактируются прямо на странице; списание баллов при нажатии "Забрать", с проверкой достаточности баланса.
- Возможность добавить свою награду без ограничения по заранее заданному списку.
- История последних начислений и списаний по каждому ребёнку.
- Редактируемый блок общих правил семьи (текст) — общий для всех.
- Автоматическое определение и подсветка текущего дня недели и диапазона текущей недели — локально, по времени устройства зрителя.
- Синхронизация состояния между устройствами без логина и без отдельного бэкенда: любое устройство, открывшее страницу, видит и меняет одно и то же состояние.
- Светлая и тёмная тема, адаптивная вёрстка (телефон/планшет/десктоп).
- Сопроводительный документ с методикой: правила, таблицы баллов, инструкция по Google Family Link, возрастные рекомендации, частые ошибки.

### Не входит в v1 (сознательно вне рамок)
- Отдельные логины/аккаунты для детей.
- Пуш-уведомления и напоминания.
- Автоматический сбор данных о реальном экранном времени с устройства (это отдаётся на откуп Google Family Link, а не этому продукту).
- Мультисемейность / поддержка нескольких домохозяйств в одном инстансе.
- Родная (native) мобильная сборка — продукт живёт как веб-страница.
- Долгосрочная история за пределами последних ~6 событий на карточку и текущей недели (нет архива по неделям).

## 5. Пользовательские сценарии

1. **Ежедневная отметка.** Ребёнок (или родитель за дошкольника) открывает страницу на своём телефоне, отмечает выполненные за день пункты. Сумма баллов за неделю обновляется сразу у всех, кто открыл страницу.
2. **Воскресный семейный совет.** Родитель с детьми открывают страницу вместе, обсуждают неделю, нажимают "Закрыть неделю" по каждому ребёнку — баллы уходят в баланс, таблица очищается для новой недели.
3. **Обмен на награду.** Ребёнок просит награду; родитель (или сам подросток) находит её в списке и нажимает "Забрать" — баллы списываются автоматически, если их достаточно, иначе показывается локальная подсказка о нехватке.
4. **Настройка под семью.** Родитель меняет имена детей, формулировки наград и их стоимость прямо на странице — без обращения к разработчику.
5. **Технический контроль.** Родитель по инструкции из сопроводительного документа настраивает Google Family Link как дополнительный, а не основной слой контроля.

## 6. Функциональные требования

| ID | Требование |
|---|---|
| FR-1 | Каждая карточка ребёнка независимо считает сумму баллов за неделю как произведение веса категории на число отмеченных дней. |
| FR-2 | Баланс — накопительное значение, изменяется только явными действиями ("Закрыть неделю", "Забрать" награду), не пересчитывается автоматически из чек-боксов. |
| FR-3 | "Закрыть неделю" недоступно к повторному начислению без новых отметок — при пустой неделе действие не создаёт запись в истории. |
| FR-4 | Списание за награду проверяет достаточность баланса до вычитания; при нехватке баланс не изменяется. |
| FR-5 | Названия наград, их стоимость и общие правила семьи редактируются непосредственно на странице (без отдельной админки). |
| FR-6 | Состояние (чек-боксы, баланс, история, тексты) видно одинаково всем, кто открыл страницу, без ручного обновления. |
| FR-7 | Определение "сегодняшнего" дня и диапазона недели выполняется на основе времени устройства каждого зрителя, а не хранится как общее состояние. |
| FR-8 | Действие "Сбросить неделю" требует повторного подтверждающего нажатия в течение нескольких секунд. |

## 7. Нефункциональные требования

- **Без установки:** открывается по ссылке в браузере на любом Android-устройстве.
- **Без учётных записей детей:** доступ по общей ссылке, которой владелец делится с семьёй.
- **Устойчивость к офлайну одного участника:** если кто-то временно офлайн, при следующем открытии видит актуальное состояние; параллельные изменения не должны молча теряться.
- **Приватность:** никаких персональных данных за пределами введённых семьёй имён и текста правил; страница не публикуется публично без явного действия владельца.
- **Доступность:** читаемый контраст в обеих темах, различимые кликабельные зоны на мобильном экране.

## 8. Модель данных (концептуально)

```
Ребёнок (карточка)
 ├─ имя (редактируемый текст)
 ├─ возрастная группа (фиксирована при создании)
 ├─ баланс (число)
 ├─ категории[] (недельная таблица)
 │    ├─ название
 │    ├─ вес в баллах
 │    └─ отметки[Пн..Вс] (булево)
 ├─ награды[]
 │    ├─ название (редактируемый текст)
 │    └─ стоимость (редактируемое число)
 └─ история[] (последние ~6 записей: текст, дата)

Правила семьи (общий редактируемый текст, один на всю страницу)
```

Данные хранятся как часть самой страницы (живой документ), отдельной базы данных нет.

## 9. Текущая реализация

- Формат: одностраничное веб-приложение (HTML/CSS/JS), опубликовано как приватная страница с собственной ссылкой.
- Синхронизация между устройствами семьи встроена в платформу публикации — специального сервера или базы данных разворачивать не нужно.
- Дизайн: тёплая бумажная палитра с зелёным/золотым акцентом, отдельный акцентный цвет на карточку ребёнка для быстрой визуальной навигации; заголовки — Fraunces, текст — Public Sans, цифры — IBM Plex Mono.
- Проверено: пересчёт суммы по чек-боксам, закрытие недели, начисление/списание баланса, добавление своей награды, двойное подтверждение сброса — вручную протестированы сценарии на реальном рендере страницы.

## 10. Риски и открытые вопросы

- **Риск потери интереса после первых недель.** Смягчается тем, что награды и баллы редактируются семьёй самостоятельно — систему можно "освежить" без переразработки.
- **Риск конфликта одновременных правок** (два человека одновременно закрывают неделю одному ребёнку) — платформа синхронизации разрешает конфликт последней принятой версией; отдельного UX для этого случая нет.
- **Открытый вопрос:** нужна ли история по неделям (архив), если семья захочет смотреть динамику за месяц/четверть — сейчас доступны только последние события, а не полный журнал.
- **Открытый вопрос:** стоит ли добавить напоминание (например, в конце дня), учитывая, что push-уведомления сознательно исключены из v1.

## 11. Возможные направления v2 (не запланировано, кандидаты)

- Архив закрытых недель с простым графиком динамики баллов.
- Раздел "серии" (streak) — сколько дней подряд закрыт день без пропуска.
- Общесемейный агрегированный показатель (например, суммарные баллы всех детей за месяц) для общей семейной награды.
- Более мягкая версия для 15–17 лет с недельными, а не ежедневными отметками — по решению самого подростка.
